# @cldmv/eslint-plugin-jsonv v1.0.11 Changelog

**Release Date**: September 2026
**Release Type**: Patch
**Availability**: npm (published 2026-09-28) and GitHub Release ([v1.0.11](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/releases/tag/v1.0.11))

---

## Overview

Version 1.0.11 fixes two correctness problems in the language: parse errors now report where they occur instead of at `1:1`, and language options are validated instead of silently accepting typos. It also adds the plugin's first test suite, with coverage in CI.

---

## 🐛 Bug Fixes

### Parse errors report at their real position ([#24](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/24), fixes [#20](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/issues/20))

`@cldmv/jsonv` used to throw syntax errors with the position only in the message text, so `parse()` reported every parse error at line 1, column 1. With `@cldmv/jsonv` 1.0.10, which exposes the error's line, column and offset, the plugin reports each parse error where it occurs.

### Language options are validated, and the language object is cleaned up ([#23](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/23), fixes [#21](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/issues/21))

- `validateLanguageOptions` was defined twice, and the second definition silently replaced the first. There is now one, and it validates the supported options, so an unknown key or an invalid value throws instead of passing silently.
- Fields ESLint never reads were removed: `defaultParserOptions`, and the `parser` entry in `configs.recommended.languageOptions`.
- The plugin `meta` (`name`, `version`) is read from `package.json`. It previously said `eslint-plugin-jsonv` `0.1.0`.

## 🔧 CI & tooling

- A vitest suite, run through `@cldmv/vitest-runner`, covers the language, the configs and ESLint integration, and CI now runs it with a coverage badge. `index.mjs` is at 100% coverage ([#18](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/18)).
- The v4 workflows are synced with the CLDMV/.github v4.29.0 templates ([#17](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/17)).

## 📚 Documentation

- `LICENSE` now contains the verbatim Apache-2.0 license text ([#16](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/16)).

## 🔧 Dependencies

- `@cldmv/jsonv` `^1.0.2` → `^1.0.10` (peer and dev dependency), for positioned parse errors.

---

## Upgrade notes

- Install `@cldmv/jsonv` 1.0.10 or later alongside this version.
- Configs with unknown or invalid `languageOptions` now fail with a validation error instead of being silently accepted. Fix the option names or values it reports.
