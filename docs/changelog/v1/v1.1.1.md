# `@cldmv/eslint-plugin-jsonv` v1.1.1 Changelog

**Release Date**: November 2026
**Release Type**: Patch
**Branch**: `release/1.1.1`

---

## Overview

v1.1.0 set `engines.node` to `>=22.22.0`, which is the Node.js version the dev toolchain needs, not the version the plugin needs. This release puts `engines.node` back to `^20.19.0 || ^22.13.0 || >=24`, the range the plugin's runtime dependencies support, and records the dev toolchain floor separately in npm's `devEngines`. Node.js 20.19+ and 22.13 through 22.21 can install the plugin again without an `EBADENGINE` warning.

The plugin's rules, language and options are unchanged. The only code change is the wording of the error the CommonJS entry throws on a Node.js version without `require(esm)`.

---

## 🐛 Bug Fixes

### `engines.node` describes the runtime again ([#88](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/88))

- `engines.node` is `^20.19.0 || ^22.13.0 || >=24` again, matching what `@eslint/core` 1.2.1 and `@eslint/plugin-kit` 0.7.3 declare. Node.js 22.22.0 is only the floor for building and testing the package, so it no longer blocks consumers.
- The CommonJS entry's `ERR_REQUIRE_ESM` message now says `require()` needs Node.js ^20.19.0 or >=22.13.0 (the versions with `require(esm)`), instead of >=22.22.0.

---

## 📦 Requirements

- **Runtime:** Node.js `^20.19.0 || ^22.13.0 || >=24` (`engines.node`), ESLint `^9.13.0 || ^10.0.0` and `@cldmv/jsonv` `^1.1.0` as peers.
- **Development:** Node.js 22.22.0 or later, declared in the new `devEngines.runtime` field (`onFail: "error"`), so npm stops with an error when it is run in a checkout on an older Node.js.

---

## 🔧 CI & tooling

- The `min_node_version` input descriptions and a comment in `ci.yml` and `publish.yml` now say the 22.22.0 matrix floor is the dev toolchain floor and should match `devEngines`, not `engines` ([#88](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/88)). The matrix itself still starts at 22.22.0.

## Upgrade notes

- No breaking changes. Anyone who stayed on v1.0.17 because of v1.1.0's Node.js 22.22.0 requirement can upgrade on Node.js 20.19+ or 22.13+.
