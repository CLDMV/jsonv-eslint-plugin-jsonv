# `@cldmv/eslint-plugin-jsonv` v1.0.17 Changelog

**Release Date**: October 2026
**Release Type**: Patch
**Branch**: `release/1.0.17`

---

## Overview

A dev-dependency release: `eslint` 10.12.0, `globals` 17.13.0, vitest 5.0.3, `@cldmv/vitest-runner` 1.5.3, the `@cldmv/jsonv` and `@cldmv/prettier-plugin-jsonv` 1.1.3 releases, and `@types/node` 26.6.4. One consequence worth knowing about: the test runner now declares Node.js 22.12 as its minimum, which is stricter than the `^20.19.0` entry in this package's own `engines` range, and it pulls in `chalk` 6.

No plugin code, published file or declared dependency range changed. The net diff against v1.0.16 is the lockfile and the `version` field of `package.json`; every range in `package.json` (including the `eslint` and `@cldmv/jsonv` peer ranges and the dev ranges) is untouched, so each update below is a lockfile-only move within an existing range. The package has no `dependencies`, only the two peers, and every package that moved is a development dependency or a transitive of one.

---

## 🔧 Dependencies

All updates are development-only, grouped by Dependabot into four pull requests ([#59](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/59), [#60](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/60), [#62](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/62), [#64](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/64)).

- `eslint` 10.11.0 → 10.12.0 ([#60](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/60)). This is the version the plugin's tests and lint run against. The published `eslint` peer range (`^9.13.0 || ^10.0.0`) is unchanged.
- `globals` 17.12.0 → 17.13.0 ([#62](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/62)).
- `vitest` 5.0.2 → 5.0.3 ([#59](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/59)), with `@vitest/coverage-v8`, `@vitest/mocker` and `@vitest/spy` following to 5.0.3. Transitive: `vite` 8.3.1 → 8.3.2, `rolldown` and its platform bindings 1.2.11 → 1.2.12, `@oxc-project/types` 0.151.0 → 0.152.0, and `why-is-node-running` 3.2.2 → 3.2.1 (pinned by vitest 5.0.3).
- `@cldmv/vitest-runner` 1.5.1 → 1.5.3 ([#64](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/64)). The runner's 1.5.3 release makes its CommonJS entry fail with a clear error on a Node.js version without `require(esm)` and raises its `engines.node` from `>=20.19.0` to `>=22.12.0`. The locked package's license field also changes from MIT to Apache-2.0. Its `chalk` dependency moves from 5.x to 6, so the locked `chalk` goes 5.6.2 → 6.0.1 with `engines` changing from `^12.17.0 || ^14.13 || >=16.0.0` to `>=22`. Both are reached only through the test runner.
- `@cldmv/jsonv` 1.1.1 → 1.1.3 and `@cldmv/prettier-plugin-jsonv` 1.1.0 → 1.1.3 ([#64](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/64)). Their releases are CI-workflow changes in those repositories (the in-repo PR mirror job now runs instead of being skipped) plus a tooling bump in `@cldmv/jsonv`. Both still declare `node >=18.0.0`, and the prettier plugin's peer ranges are unchanged. `@cldmv/jsonv` is also a peer dependency of the published plugin (`^1.1.0`, unchanged); the move to 1.1.3 only changes which version the plugin's own tests run against, and 1.1.3 satisfies that range.
- `@types/node` 26.6.3 → 26.6.4 ([#64](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/64)).

### Node.js floors

This package's `engines.node` stays `^20.19.0 || ^22.13.0 || >=24`, and that range describes who can **install and run the plugin**, which depends on none of the packages above. The **development** toolchain already required Node.js 22.12 (`vitest` 5, `@cldmv/fix-headers`), and `@cldmv/vitest-runner` now says so too. The CI matrix starts at 22.12.0, so CI is unaffected; a contributor on Node.js 20 cannot run the test suite, as before.
