# @cldmv/eslint-plugin-jsonv v1.0.0 Changelog

**Release Date**: January 2026
**Release Type**: Major (initial release)
**Availability**: npm (published 2026-01-19)

---

## Overview

The first release of `@cldmv/eslint-plugin-jsonv`: an ESLint flat-config plugin that validates `.jsonv` files with the real [`@cldmv/jsonv`](https://github.com/CLDMV/jsonv) parser.

---

## ✨ Features

- A `jsonv/jsonv` language for ESLint's flat config, with a `recommended` config.
- Syntax validation by the jsonv parser itself, covering the JSON5 (ES2011) base and the ES2015, ES2020 and ES2021 additions: binary and octal literals, BigInt, numeric separators and template interpolation.
- Internal-reference validation: undefined and circular references are reported.
- A `year` language option that selects which ES-year features are accepted.
- Bundled ESM output (`dist/index.mjs`) with generated type declarations.

## 🔧 Dependencies

- Peer dependency: `@cldmv/jsonv` `^1.0.0`.
