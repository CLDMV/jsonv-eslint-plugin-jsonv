# @cldmv/eslint-plugin-jsonv v1.0.15 Changelog

**Release Date**: October 2026
**Release Type**: Patch

---

## Overview

A dev-dependency and CI release. No plugin code changed. The development copy of `@cldmv/jsonv` moves to 1.1.1, and the tests that assert the parser's exact diagnostics are updated for that release's behavior — which is also what a project linting with `@cldmv/jsonv` 1.1.1 installed will see, since the plugin reports the parser's errors as-is.

---

## 🔧 CI & tooling

### Run the in-repo PR mirror job instead of skipping it ([#52](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/52))

The fix in [v1.0.14](./v1.0.14.md) gave the mirror job a conditional name so a skipped run would not report under the required name, but GitHub does not evaluate the `name:` of a skipped job, so the skipped run showed up under the raw expression text. The job now always runs (`if: always()`), so its name is always evaluated: on the paths that own the status it reports as `✅ Required PR Check` and mirrors the test matrix's result, and on an in-repo feature PR's `pull_request` run it reports as `⏭️ Required PR Check (reported by the push run)` and exits as a no-op.

### Tests updated for `@cldmv/jsonv` 1.1.1 ([#50](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/50))

`@cldmv/jsonv` 1.1.1 changes three things the tests pinned exactly, none of them in this plugin:

- A circular internal reference (`{ a: b, b: a }`) now reports `Circular reference: a -> b -> a`, positioned on the reference that closes the cycle, instead of `Unresolved reference: b (circular reference or undefined)` on the first one.
- `mode: "json"` rejects an unquoted key, so the option-forwarding tests use a quoted key that parses under every mode.
- A template literal's tail `TemplateElement` now starts at the closing `}` of the last interpolation, so its `raw` text and range include it.

## 🔧 Dependencies

- `@cldmv/jsonv` 1.1.0 → 1.1.1 within the patch group ([#50](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/50)). This is the resolved dev-dependency version; the peer range stays `^1.1.0`.
- `@cldmv/prettier-plugin-jsonv` 1.0.6 → 1.1.0 and `@cldmv/vitest-runner` 1.4.3 → 1.5.1 within the minor group ([#51](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/51), dev-only).

## Upgrade notes

- No runtime changes — drop-in for v1.0.14.
- Upgrading `@cldmv/jsonv` to 1.1.1 alongside this plugin changes two lint messages: circular references get the new `Circular reference: …` message and position, and `mode: "json"` now reports unquoted keys as errors. Both come from the parser, not the plugin.
