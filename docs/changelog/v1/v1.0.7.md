## Overview

A CI-only release: the hotfix redirector uses the v4 reusable workflow, which signs the cherry-pick it makes. No plugin code changed.

---

## 🔧 CI & tooling

- `hotfix-redirector.yml` now calls the CLDMV/.github `workflow-hotfix-redirector.yml` reusable workflow instead of inline steps. When a security PR aimed at `next` is redirected to `hotfixes`, the cherry-picked commit is signed ([#7](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/7), released in [#8](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/8)).
