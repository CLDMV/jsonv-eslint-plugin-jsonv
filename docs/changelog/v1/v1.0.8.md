# @cldmv/eslint-plugin-jsonv v1.0.8 Changelog

**Release Date**: September 2026
**Release Type**: Patch
**Availability**: GitHub Release only ([v1.0.8](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/releases/tag/v1.0.8)); not published to npm

---

## Overview

A CI-only release that moves the Node test matrix to the range vitest 5 runs on. No plugin code changed.

---

## 🔧 CI & tooling

- The CI and publish Node matrices move from Node 20–22 to **22.12.0–26**. Node 22.12.0 is the lowest version vitest 5 runs on ([#9](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/9), released in [#10](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/10)).

---

## Upgrade notes

- No runtime changes. This changes only which Node versions CI tests on; the package's own `engines` field is unchanged.
