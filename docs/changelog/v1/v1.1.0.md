# `@cldmv/eslint-plugin-jsonv` v1.1.0 Changelog

**Release Date**: November 2026
**Release Type**: Minor
**Branch**: `release/1.1.0`

---

## Overview

The plugin moves to the CLDMV library layout. Its source now lives in `src/`, the published `dist/index.mjs` is a tsup bundle instead of a verbatim copy of the root `index.mjs`, and the package gains a CommonJS entry, so an `eslint.config.cjs` can `require("@cldmv/eslint-plugin-jsonv")` and get the plugin object. An `eslint-plugin-jsonv-dev` export condition lets a checkout run straight from `src/`. The plugin's rules, language and options are unchanged, as are its runtime dependencies and peer ranges.

The package now declares `engines.node` `>=22.22.0`, narrowed from `^20.19.0 || ^22.13.0 || >=24`. That drops Node.js 20 and 22.13 through 22.21, so it is a real requirement change; see the upgrade notes.

## ✨ Features

### Source in `src/`, tsup build and a `require()` entry ([#83](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/83), closes [#82](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/issues/82))

- **`src/index.mjs`.** The plugin moved from the repository root to `src/index.mjs`. Both the source and the build now sit one directory below the package root, so the plugin always reads its `name` and `version` from `../package.json`; the co-located lookup and its fallback are gone.
- **tsup build.** tsup replaces `scripts/build.mjs` and bundles `src/index.mjs` into `dist/index.mjs`, minified with function and class names kept and `node:` specifiers preserved. The runtime dependencies (`@eslint/core`, `@eslint/plugin-kit`) and the peers (`@cldmv/jsonv`, `eslint`) stay external. `dist/index.d.mts` is still generated from the JSDoc.
- **CommonJS entry.** `src/index.cjs` is copied verbatim to `dist/index.cjs`. It loads the ESM build through Node's `require(esm)` and exports its default export, so `require()` returns the same plugin object as `import`. On a Node.js version without `require(esm)` it throws `ERR_REQUIRE_ESM` with a message naming the supported range and pointing at `import()`. `main` now points at `dist/index.cjs`, and `exports` gains `require` and a `./package.json` entry.
- **`eslint-plugin-jsonv-dev` export condition.** In a checkout, `node --conditions=eslint-plugin-jsonv-dev` resolves `import` and `require` of the package to `src/`. The Vitest suite runs against `src/` through the condition, and `npm run test:dist` builds the package and checks `dist/index.cjs` with `node --test`.
- `prepack` builds the package, and sourcemaps are generated for local debugging but left out of the published tarball.

## 🔧 CI & tooling

- **Node.js floor raised to 22.22.0** ([#83](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/83)). The dev toolchain (`tsup` 9 and its `chokidar` 6 dependency) needs Node.js 22.22, so nothing older can be built or tested. `engines.node`, the CommonJS guard message and the CI matrix floor (previously 22.12.0) move together.
- `build:ci` runs lint, the format check, the build and the type tests; CI's coverage legs run `build:ci`, and the bundle-size check measures the real `dist/` files.
- **TypeScript pinned to 6** ([#85](https://github.com/CLDMV/jsonv-eslint-plugin-jsonv/pull/85)). The declaration build was on TypeScript 7.0.2, whose JavaScript declaration emit isn't complete yet; it now uses `typescript` `^6.0.3` (6.0.3).

## Upgrade notes

- **Node.js 22.22.0 or later is now required.** v1.0.17 declared `^20.19.0 || ^22.13.0 || >=24`. On Node.js 20 or 22 before 22.22.0, npm warns with `EBADENGINE` on install (or refuses, with `engine-strict`), and those versions are no longer built or tested.
- `import jsonv from "@cldmv/eslint-plugin-jsonv"` works as before. A CommonJS config can now use `require("@cldmv/eslint-plugin-jsonv")`, which returns the same plugin object.
- No rule, language or option changed, so lint results are the same as with v1.0.17.
